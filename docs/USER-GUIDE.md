# RPA 原版精简本地版 0.1.1

基于本机原版 6.0.20230616.77 的界面、流程图编辑器、项目解析器和命令组件，新增本地入口。原厂 EXE/DLL 保持原样；新增入口负责独立配置、离线初始化和界面精简。

## 使用

双击 `RpaStudioLocal.exe`，直接进入原版首页。通过“打开”选择旧项目的 `.proj` 文件，也可把 `.proj` 拖到这个 EXE 上。

迁移旧项目时，请复制整个项目文件夹，包括 `main.flow`、`main` 子目录、`.script`、资源和依赖文件。只复制 `.proj` 文件不包含实际流程及命令内容。

在原界面中双击执行单元或子流程，即可进入原来的嵌套编辑页。新建、命令拖放、参数编辑、保存、另存为和调试均使用原模块。首次编辑重要旧项目时，建议先打开项目副本。

## 此版变化

- 默认入口不显示登录窗口，不创建远程登录会话。
- 隐藏账号操作、模板商城、“获取更多”和发布入口；停用首页在线推荐。
- 使用原执行引擎的 Offline 模式，保留本地编辑与运行。
- 不自动安装浏览器扩展，不启动原自动更新程序。
- 将 34 个原命令库及其依赖封装进一个 EXE，可加载 322 条命令定义。
- 去掉打包内容中的旧日志、PDB、安装缓存、账号数据库和业务项目。
- 补齐 0.1 包遗漏的浏览器插件 JS、HTML、CSS、图标、清单及安装辅助文件；不自动执行注册。
- 提供每用户 MSI，创建开始菜单和桌面快捷方式；标准卸载保留运行配置及项目。

## DLL 的集成方式

这是一个内置压缩组件包的启动 EXE。首次启动自动展开到：

`%LOCALAPPDATA%\RpaStudioLocal\Versions\<组件版本标识>`

实际运行时仍从该目录加载 DLL，以保留原程序对文件路径、WPF 资源、插件及 SQLite 原生组件的要求。无需手动复制 DLL。启动器逐项校验文件；缺失或内容损坏的打包组件会从 EXE 内重新恢复。

本地配置、收藏和默认项目存放在展开目录中的 `LocalConfig`、`Config`、`Scripts`、`UserCommandLibs`。不要把整个展开目录当作临时文件清理；业务项目也可以新建在自行选择的其他目录。此版不修改 `C:\seentao\YonyouRpaStudio` 原安装。

## 已验证与边界

- 全新配置目录中，523 个打包文件可展开并校验；原命令树生成 381 个节点。
- 旧项目副本可打开主流程和嵌套执行单元；63 条动作（含嵌套动作）及参数在保存后重开保持一致。
- 原模块可新建、保存空白项目。
- 原执行引擎在离线模式下通过“开始 → 原注释命令 → 结束”的基础运行检查；没有执行业务或付款流程。

命令显示和基础运行通过，不代表每项外部集成都已适配当前环境。浏览器、Office、SAP、OCR 和联网命令仍需要各自的软件、插件、服务或原有合法授权。内置 ChromeDriver 为原包的 114 版，浏览器自动化需匹配目标电脑的浏览器版本。远程登录、云调度、商城及云发布不在此本地版范围内。

适用 Windows，需要 .NET Framework 4.8。首次启动需要写入当前用户的本地应用目录。

MSI 默认安装在 `%LOCALAPPDATA%\Programs\RpaStudioLocal`。卸载会删除该安装目录中的程序与快捷方式，保留 `%LOCALAPPDATA%\RpaStudioLocal` 的配置及项目。组件包改变时会创建新运行目录，旧配置不会自动迁移；旧项目仍可从原位置打开。请勿删除旧目录后再查找项目。

## 排查

启动器校验结果：`%LOCALAPPDATA%\RpaStudioLocal\last-check.txt`。

本地入口日志：展开目录中的 `LocalConfig\host.log`。原模块运行日志位于 `net461\log`。分享日志前，请自行检查其中是否含有业务数据。

可使用 `RpaStudioLocal.exe --verify` 只检查组件加载；不打开或执行业务项目。

## 构建

`Build.ps1 -Original <原安装>` 从指定原安装复制静态组件，编译新增入口并生成单 EXE。`scripts/Build-Msi.ps1` 生成 MSI。`tests/Test-Host.ps1` 在隔离目录生成开发验证入口，测试入口不会进入发布包。

这里的源码是新增本地入口、打包器和验证程序的源码，不包含未取得的原厂程序源码。`validation` 目录包含私有项目副本，不能纳入发布包；构建脚本使用明确的静态组件目录清单。
